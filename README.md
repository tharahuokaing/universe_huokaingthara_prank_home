## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_prank_home`** serves as the prank and comedy entertainment hub for **UNIVERSE HUOKAING THARA Group**. Visitors can filter featured segments by category, search titles and keywords in real time, and inspect format and production notes inside an episode brief modal.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Live Search & Category Filtering:** Filter showcases by category (*Comedy, Reactions, Friendly Games*) or search titles, formats, and keywords in real time.
* **🎭 Episode Brief Modal:** Inspect each segment's category, format, and production notes inside a modal window.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់
